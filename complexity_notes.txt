2. Sorting by Book ID
Algorithm: C++ std::sort()
Time Complexity: O(n log n) average
Space Complexity: O(log n) auxiliary space
Purpose: Sorts books in ascending order of book ID.

3. Book Searching
Algorithm: Linear Search
Time Complexity: O(n)
Space Complexity: O(1)
Purpose: Searches the library for a book matching the given title.

4. Library Report
Algorithm: Single traversal of the books collection
Time Complexity: O(n)
Space Complexity: O(1)
Purpose: Counts total, available, and issued books.
